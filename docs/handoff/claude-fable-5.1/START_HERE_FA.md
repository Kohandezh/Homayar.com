# بستهٔ شروع Homayar برای Claude

این بسته برای مدلی تهیه شده که شما با نام «Claude Fable 5.1» در Claude انتخاب می‌کنید. شناسهٔ API یا قابلیت اختصاصی برای این نام فرض نشده است؛ مدل را در خود Claude انتخاب کنید.

## چه چیزی آماده شده؟

- گزارش کامل ۴۰ بخشی محصول، کسب‌وکار، امنیت و معماری.
- ۹۵ قابلیت اولویت‌بندی‌شده و ۶۴ معیار پذیرش P0/P1.
- ۲۴ پوشهٔ بستهٔ کاری، شامل ۱۶۱ زیرکار قابل اجرا.
- گزارش وضعیت فعلی و همهٔ کارهای باقی‌مانده.
- نقشهٔ تازهٔ کد و گراف جداگانهٔ وابستگی‌های برنامه.
- موجودی مهارت‌های Claude، دستورالعمل آماده‌سازی و پرامپت شروع/ادامه.

کد اجرایی سایت، API و کنسول تغییر نکرده است. مهارتی نصب یا ارتقا داده نشده، commit/deploy انجام نشده و هیچ کلید یا دادهٔ مشتری وارد این بسته نشده است. پوشه‌بندی انجام‌شده مربوط به مستندات، برنامهٔ اجرا و فایل‌های تحویل است؛ جابه‌جایی معماری کد به مرحلهٔ توسعه واگذار شده است.

## روش استفاده

**اگر Claude به پوشهٔ پروژه دسترسی دارد:** همین workspace را باز کنید و محتوای [MASTER_PROMPT.md](MASTER_PROMPT.md) را به‌عنوان پیام شروع بفرستید. Claude باید ابتدا هر دو مخزن Git و فایل‌های راهنما را بخواند و از WP01 شروع کند.

**اگر از Claude وب یا Project استفاده می‌کنید:** فایل `CLAUDE_HANDOFF_SINGLE_FILE.md` را اضافه کنید و پرامپت شروع را ارسال کنید. فایل ZIP برای انتقال مجموعهٔ کامل مستندات و نقشه‌هاست. این بسته شامل سورس کامل برنامه نیست؛ برای اجرای واقعی، دسترسی جداگانه به مخزن لازم است. Claude نباید بدون ابزار ادعا کند کد را اجرا یا تغییر داده است.

**برای ادامهٔ جلسه:** [CONTINUE_PROMPT.md](CONTINUE_PROMPT.md) را بفرستید. عامل باید [PROGRESS.md](PROGRESS.md) را بخواند و از آخرین زیرکار ادامه دهد.

## نقطهٔ شروع پیشنهادی

WP01 برای ثبت وضعیت و تعیین قرارداد سورس/CI؛ در کنار آن آماده‌سازی فهرست امن WP02 برای صاحبان کلیدها و پروتکل داده/برچسب‌گذاری WP13. سپس قرارداد خروجی صادقانه و شواهد در WP04 و بقیهٔ پایه‌های P0.

وجود فایل یا نمودار به معنای تکمیل قابلیت نیست. نتیجهٔ ۹۷ تست موفق مربوط به ممیزی قبلی است؛ تست جدید پیاده‌سازی باید پس از هر تغییر لازم اجرا شود. انتشار، حذف داده، بازنویسی تاریخچه و تغییر کلیدها عملیات جداگانه‌اند و در این آماده‌سازی انجام نشده‌اند.
