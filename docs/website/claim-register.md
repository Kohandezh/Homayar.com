## How this register was made

- Evidence is code on main at `37fed09`: a path with a line or a symbol, and a test where one exists, or a merged PR. All paths are repo-relative.
- `Homayar/AppVision.md`, plans and Linear tickets are intent. They are used only to decide between `PLANNED` (on the roadmap) and `REMOVE` (not on the roadmap). They are never evidence that a feature exists.
- Main finding: most product copy described an older product. Its routers (`copilot`, `dashboard`, `graph`, `ldap_sync`, `webhook`) were deleted in commit `d5bbe5d` (HOM-152). On main today the analysis stage writes a summary, action items and insights, each linked to transcript evidence (`Homayar/backend/providers/openai_compatible.py:27`). There are no QC scores, four agents, PDF export, copilot, graph, VOIP webhooks or LDAP.
- Security, privacy, retention and self-hosted network claims are mostly supported as written.
- The copy change is words only. No JSX, class, style, key, scene or timing changed. Four roadmap lists grew by one item each (free-length lists rendered with `.map`). Two hard-coded chips changed text.
